# FreshCart Market POS

A single page Point of Sale screen for a supermarket checkout, built for a JavaScript course assignment. A cashier can pick products, build the customer's order, see the totals, and complete the sale with a receipt.

Built with HTML, CSS, and plain JavaScript. There are no frameworks, libraries, or backend.

## Status

Work in progress. The project structure is in place and features are being added one phase at a time.

## How to run

Download or clone the project and open `index.html` in a web browser. No installation or server is needed.
